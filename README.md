# Kiran K — Professional React Portfolio

Recruiter-focused portfolio built with React + Vite + Framer Motion.

## Features
- Responsive professional dark UI
- Smooth navigation
- Scroll-reveal and hover animations
- Profile and secondary photos supplied by you
- Recruiter snapshot
- Experience timeline
- Skills grouped by category
- Projects
- Resume download
- Email, phone, LinkedIn and GitHub links

## Run
```bash
npm install
npm run dev
```
Then open the localhost URL shown by Vite.

## Production
```bash
npm run build
```

## Eclipse
Eclipse can be used as the editor. Vite/Node runs the application, not Tomcat.

1. Extract the ZIP.
2. Eclipse -> File -> Import -> General -> Projects from Folder or Archive.
3. Select `kiran-professional-portfolio`.
4. Open Eclipse Terminal.
5. Run `npm install`.
6. Run `npm run dev`.
7. Open the localhost URL printed by Vite.

Do not use `Run on Server` / Tomcat.

## Customize
- Content: `src/App.jsx`
- Styling: `src/styles.css`
- Profile: `public/images/profile.jpg`
- Secondary photo: `public/images/kk.jpg`
- Resume: `public/Kiran_K_Resume.pdf`
